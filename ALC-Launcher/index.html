Open programs with one click

Web browsers are not allowed to start programs on your PC, so this page can only copy the program's path. The desktop version of ALC Launcher opens programs directly.

  1. Click Download desktop app below.
  2. Right-click the downloaded zip, choose Extract All, and put the folder somewhere permanent (for example Documents).
  3. Open the folder and double-click ALC Launcher.exe. If Windows says it protected your PC, click More info > Run anyway.
  4. Optional: right-click its taskbar icon > Pin to taskbar.

Versions and paths

Browsers are not allowed to see where files are on your PC, so the path has to be pasted in. In File Explorer, find the program, right-click it and choose Copy as path (or select it and press Ctrl+Shift+C). Then click the path box and press Ctrl+V.

Icon

Pick a PNG, JPG, SVG, ICO or similar. Without one, the tile uses the program's own icon, or the badge text if no path is set.

In the browser version, web links (https://...) open directly. A program path such as C:\...\app.exe is copied when you click the tile, so you can paste it into Start or Run (Win+R).
