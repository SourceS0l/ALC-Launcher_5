Versions and paths

Browsers are not allowed to see where files are on your PC, so the path has to be pasted in. In File Explorer, find the program, right-click it and choose Copy as path (or select it and press Ctrl+Shift+C). Then click the path box and press Ctrl+V.

Icon

Pick a PNG, JPG, SVG, ICO or similar. Without one, the tile uses the program's own icon, or the badge text if no path is set.

In the browser version, web links (https://...) open directly. A program path such as C:\...\app.exe is copied when you click the tile, so you can paste it into Start or Run (Win+R).
